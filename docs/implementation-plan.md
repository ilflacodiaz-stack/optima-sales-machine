# Implementation Plan

## Week 13: System Design And State

Deliverables:

- choose shared state store
- create prospect/research/outreach schemas
- write or adapt the three SOUL files
- define daily run format
- connect Telegram reporting

Definition of done:

- you can manually add a prospect to state
- Research Agent can read it
- Outreach Agent can generate drafts from a sample brief

## Week 14: Scout Agent

Deliverables:

- Scout SOUL
- first source tool for Zonaprop / Argenprop discovery
- dedupe logic
- daily scout report

Definition of done:

- Scout finds at least 3 candidate inmobiliarias
- Scout explains why each candidate passed or failed
- candidates are written to shared state

## Week 15: Research Agent

Deliverables:

- adapt James into the Research Agent role
- add CRM / competitor signal checklist
- write research briefs to shared state
- qualify prospects

Definition of done:

- Research Agent enriches 3 Scout prospects
- each prospect has score, signals, risks, and outreach angle

## Week 16: Outreach Agent

Deliverables:

- Outreach SOUL
- WhatsApp, email, LinkedIn drafting
- Telegram daily summary
- human review workflow

Definition of done:

- every qualified prospect gets three channel drafts
- you receive one morning Telegram report
- you can track which drafts were sent
